# 新增 smartpage.blocks.update（3.1 KB）：
#   它是远程 MCP 下**唯一**能往智能文档写内容的方法（其余 smartpage 写入方法只接受
#   容器内本地文件路径，Agent 拿不到）。原先在 Tier2，导致 Quick 为了写一份文档
#   先误用 doc.contents.append（那是 Word 文档的接口）、再试 pages.overwrite 传路径，
#   兜了三圈才通过 discover 找到它。这是 Tier1 名单最实质的一处缺口。
#
# 保留但已在描述里标注为远程不可用的：
#   media.upload / disk.files.upload —— 只接受本地文件路径。保留在 Tier1 是因为
#   「上传文件」是高频意图，让模型能直接看到并读到「此路不通 + 该走哪」的说明，
